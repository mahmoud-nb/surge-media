surgeMedia is in **pre-release**: the first public version, 0.1.0, is ready. The shipped scope is already broad (administration, API, image transformations, video processing, Docker image), and every change goes through full continuous integration: type checks, lint, more than 700 automated tests, and a build and smoke test of the npm package and the Docker image.

Before 1.0, a minor version may contain breaking changes, always announced in the changelog. We recommend starting with a pilot project.
