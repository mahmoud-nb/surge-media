Paste the content of the `.lic` file you receive into **Settings › License**, or set it in the `NUXT_LICENSE_KEY` environment variable, which then takes precedence. The license is verified on your server, offline: surgeMedia never contacts us.

The same page shows the licensee, plan, enabled features, covered instances and dates, plus the installation identifier to include in your yearly statement of production instances. You are warned 30 days before expiry, and a 30-day grace period follows it. After that, only paid features switch off: media delivery, the API and the administration never stop.
