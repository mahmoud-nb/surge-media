---
question: "Où nos données sont-elles hébergées ?"
order: 2
keywords: ["localisation","hébergement","souveraineté","union européenne","secnumcloud","transfert"]
---
Là où vous installez la base et le stockage, sans exception : dans vos centres de données, dans un cloud européen ou dans un cloud qualifié SecNumCloud.

Aucune donnée ne transite par l’éditeur. Vous maîtrisez donc entièrement les éventuels transferts hors de l’Union européenne.
