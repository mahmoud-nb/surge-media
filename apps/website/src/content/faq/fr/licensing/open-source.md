Son code source est **public**, sous Business Source License 1.1 : vous pouvez le lire, le modifier et l’auto-héberger. Ce n’est pas encore une licence open source au sens de l’OSI, mais chaque version passe automatiquement sous **Apache 2.0** trois ans après sa publication.

Les bibliothèques front `@surge-media/client` et `@surge-media/vue` sont sous licence MIT.
