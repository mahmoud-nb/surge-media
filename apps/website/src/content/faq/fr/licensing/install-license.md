Collez le contenu du fichier `.lic` reçu dans **Réglages › Licence**, ou placez-le dans la variable d’environnement `NUXT_LICENSE_KEY`, qui l’emporte alors. La licence est vérifiée sur votre serveur, hors ligne : surgeMedia ne nous contacte jamais.

La même page affiche le titulaire, l’offre, les fonctions activées, les instances couvertes et les dates, ainsi que l’identifiant de l’installation à reporter dans votre déclaration annuelle des instances de production. Vous êtes averti 30 jours avant l’échéance, puis une période de grâce de 30 jours suit. Ensuite, seules les fonctions payantes s’éteignent : la diffusion des médias, l’API et l’administration ne s’arrêtent jamais.
