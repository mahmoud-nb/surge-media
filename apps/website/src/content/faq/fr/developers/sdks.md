- `@surge-media/client` : un client JavaScript sans dépendance (API, URL d’images, file d’envoi) ;
- `@surge-media/vue` : des composants d’affichage et d’envoi (`SmImage`, `SmPicture`, `SmVideo`, `SmUploader`…).

Les deux sont sous licence MIT. Les paquets React, Svelte et Nuxt sont prévus. Pour un autre langage, générez un client à partir du document OpenAPI.
