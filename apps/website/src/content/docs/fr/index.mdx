<Section
  id="transformations"
  eyebrow="Transformations à la volée"
  title="Toutes les tailles, tous les formats. À une URL près."
  lead="Envoyez l’original une seule fois. surgeMedia génère la variante demandée par votre page à la première requête, la conserve, puis la sert avec un cache immuable."
>

<Tabs syncKey="showcase">
<TabItem label="HTML responsive" icon="seti:html">

```html
<picture>
  <source type="image/avif" srcset="https://media.example.com/m/k7d2m9qz/v3/w_800,h_450/hero.avif" />
  <source type="image/webp" srcset="https://media.example.com/m/k7d2m9qz/v3/w_800,h_450/hero.webp" />
  <img src="https://media.example.com/m/k7d2m9qz/v3/w_800,h_450/hero.jpg"
       width="800" height="450" alt="Notre nouvelle collection" />
</picture>
```

</TabItem>
<TabItem label="Anatomie d’une URL" icon="seti:default">

```text
https://media.example.com/m/k7d2m9qz/v3/w_800,h_450,g_focal,q_70/hero.avif
                            └──┬───┘ └┬┘ └─────────┬──────────┘ └──┬─────┘
                             média  version   transformation   nom.format
```

- **`w_` / `h_`** fixent la taille, **`fit_`** la stratégie (`cover`, `contain`, `inside`…), **`g_focal`** garde le sujet dans le cadre.
- **L’extension est le format** : `jpg`, `png`, `webp` ou `avif`. Les images ne sont jamais agrandies et leurs métadonnées (EXIF, GPS) sont retirées.
- **Les préréglages** (`preview` intégré, ou les vôtres comme `card` ou `og-image`) donnent un nom à une transformation. Un projet peut aussi n’accepter que des préréglages, ou que des URL signées.

</TabItem>
<TabItem label="Depuis l’API" icon="seti:json">

```json
// GET /api/v1/projects/{projectId}/media/{mediaId}
{
  "id": "k7d2m9qz",
  "kind": "image",
  "width": 4032,
  "height": 3024,
  "altText": "Notre nouvelle collection",
  "focalPoint": { "x": 0.62, "y": 0.4 },
  "urlTemplate": "https://media.example.com/m/k7d2m9qz/v3/{transform}/hero.{format}"
}
```

Remplacez `{transform}` et `{format}` côté client pour construire n’importe quel `srcset` — sans requête supplémentaire.

</TabItem>
</Tabs>

</Section>

<Tabs syncKey="install">
<TabItem label="npm / npx" icon="npm">

```bash
# Dans le dossier qui contiendra votre configuration et vos données (Node.js 24 ou plus)
npm install @surge-media/core
npx surge-media init    # au choix : SQLite, PostgreSQL ou MySQL / MariaDB
npx surge-media start   # administration, API et diffusion sur http://localhost:3000
```

</TabItem>
<TabItem label="Docker" icon="seti:docker">

```bash
docker run -d --name surge-media -p 127.0.0.1:3000:3000 \
  -v surge-media-data:/app/data \
  -e NUXT_SITE_URL=https://media.example.com \
  -e NUXT_BOOTSTRAP_ADMIN_EMAIL=vous@example.com \
  -e NUXT_BOOTSTRAP_ADMIN_PASSWORD='une-longue-phrase-secrete' \
  ghcr.io/mahmoud-nb/surge-media
```

</TabItem>
<TabItem label="Compose + PostgreSQL" icon="seti:config">

```bash
# Serveur web + processus vidéo + PostgreSQL 17, depuis le dossier docker/ du dépôt
POSTGRES_PASSWORD='a-changer' docker compose -f docker/compose.postgres.yaml up -d
```

</TabItem>
</Tabs>
